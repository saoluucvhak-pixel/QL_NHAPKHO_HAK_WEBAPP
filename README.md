# QL_NHAPKHO_HAK_WEBAPP — Hệ thống quản lý cân / nhập–xuất kho HAKGROUP

Google Apps Script Web App: import phiếu cân, nhập liệu kho gỗ keo & dăm, báo giá, xuất hàng, báo cáo & Misa, dashboard.

| File | Vai trò |
|---|---|
| `Code.gs`, `Config.gs`, `Index.html`, `appsscript.json` | Mã nguồn Apps Script (chỉ 4 file này được đưa lên Apps Script) |
| `tests/` | Kiểm thử tự động (`npm test`, `npm run test:ui`) |
| `docs/` | Báo cáo đánh giá, hướng dẫn triển khai / sử dụng / lập trình, kiểm thử |
| `CHANGELOG.md` | Lịch sử phiên bản |
