# HƯỚNG DẪN SỬ DỤNG (tóm tắt)

> Hướng dẫn chi tiết từng màn hình có sẵn trong webapp: **Hệ thống › Hướng dẫn sử dụng** và **Quy trình tổng quan**.

## Đăng nhập
1. Mở webapp (hoặc mục "Kho gỗ keo" trên Portal) → **Đăng nhập bằng Gmail**.
2. Cửa sổ Cổng hiện ra (lần đầu: cho phép xem email) → **Vào hệ thống**. Cửa sổ tự đóng, hệ thống tự vào.
3. Phiên đăng nhập giữ tối đa 12 giờ (không thao tác 6 giờ sẽ hết). **Đăng xuất** ở góc dưới thanh bên.
4. Muốn đổi tài khoản: đăng xuất Google hoặc dùng cửa sổ ẩn danh.

## Vai trò
| Vai trò | Được làm |
|---|---|
| Quản trị | Mọi chức năng + Cấu hình hệ thống, Người dùng & Cổng, Lưu trữ |
| Nhân viên | Import, nhập liệu, báo giá, báo cáo, xuất file |
| Chỉ xem | Dashboard, báo cáo, danh sách, xuất Excel/PDF — không nhập/sửa/xóa |

## Công việc hằng ngày
| Việc | Menu |
|---|---|
| Nhập phiếu cân từ file Excel | Import › Nhập kho theo phiếu cân → chọn file (được nhiều file) → Xem trước → Xác nhận |
| Nhập tay phiếu gỗ keo | Nhập liệu › Nhập thủ công kho gỗ keo |
| Nhập/xuất dăm, độ khô, kỳ vét bãi | Nhập liệu › mục tương ứng |
| Đơn hàng xuất bán | Nhập liệu › Đơn hàng xuất bán (Sửa/Xóa trên danh sách) |
| Báo giá | Quản lý báo giá › Nhập báo giá / Hiệu lực báo giá |
| Báo cáo & xuất file | Báo cáo tổng hợp kho › chọn báo cáo → Lọc → Xuất Excel/PDF (file tự tải về máy) |

## Lưu ý
- Kỳ vét bãi cũ đã **khóa sổ**: không sửa/xóa phiếu thuộc kỳ cũ; chỉ xóa được kỳ mới nhất.
- Nếu hệ thống báo danh sách đã thay đổi (người khác vừa sửa/xóa) → bấm **Tải lại** rồi thao tác lại.
- Mọi thao tác ghi đều được lưu nhật ký kèm email người thực hiện.
